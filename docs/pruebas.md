# Estrategia de Pruebas y Calidad

- **Pruebas Unitarias:** Cobertura de funciones de utilidad, hashing y filtros de seguridad.
- **Pruebas de Integración:** Verificación de endpoints FastAPI y conexión con base de datos mediante Pytest y HTTPX.
- **Pruebas de LLM:** Validación de parseo JSON y manejo de mocks.
