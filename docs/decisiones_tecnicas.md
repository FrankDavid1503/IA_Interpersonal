# Decisiones Técnicas y Stack de Tecnologías

## Justificación del Stack

- **FastAPI + Python 3.10+:** Alta performance asíncrona, validación nativa con Pydantic e integración transparente con librerías de IA/LLM.
- **SQLAlchemy 2.0 + Alembic:** ORM relacional moderno con tipado fuerte y soporte total de migraciones para PostgreSQL.
- **Next.js 14 + Tailwind CSS:** Framework React para la interfaz de usuario con renderizado optimizado y diseño adaptativo.
- **JWT (JSON Web Token):** Autenticación sin estado para proteger endpoints privados.
